# Битва на горе Черепламени
Русскоязычная браузерная адаптация базовой коробки для 2–6 игроков. В режиме «С ботами» первым местом управляет человек. Режим «За одним экраном» закрывает руки шторкой. Серверные комнаты имеют отдельную ссылку зрителя.
## Запуск
Для одиночной или локальной партии откройте отдельный файл «Черепламень.html» в современном браузере.
Для сетевой игры распакуйте архив целиком. Требуется Node.js 24. В Windows откройте Play.cmd, в другом окружении выполните node server.js и откройте http://localhost:3001. Готовый веб-клиент лежит в dist/client. Установка npm-пакетов для запуска собранной версии не требуется.
В домашней сети другие игроки открывают адрес компьютера, на котором запущен сервер, с этим же портом. В браузере создайте комнату, скопируйте ссылку и займите место. Первое место начинает игру после заполнения всех мест. Для зрителя используйте ссылку с окончанием /watch.
## Разработка и Zarya
npm ci, npm test, npm run build. Проверка вёрстки в браузере — `npm run check:ui`: скрипт сам поднимает dev-сервер и гоняет Chromium (нужен `npx playwright install chromium` или переменная `CHROME` с путём к chrome.exe). Пересборка автономного HTML — node standalone.mjs путь-к-файлу.html после сборки (в файл вшиваются все сканы карт, портреты магов, карты мёртвого колдуна и фоны). Источники колоды и ядра указаны в SOURCES.md.
Сервис читает PORT, MATCHES_DIR, PUBLIC_URL, PLATFORM_SECRET. Партии по умолчанию сохраняются в data/matches. Для Docker монтируйте /data/matches. Облачная версия использует D1.
zarya-platform.patch подготовлен для коммита 290f77d платформы. В каталоге платформы можно проверить совместимость командой git apply --check путь-к-патчу, затем применить git apply путь-к-патчу. Каталог игры для конфигурации по умолчанию — ../skullzfyre-boardgame. Публикация в действующий каталог, настройка домена и общего секрета зависят от администратора площадки.
